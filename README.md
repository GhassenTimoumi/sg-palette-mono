# SG Palette — variante « Swiss Minimal »

Site vitrine bilingue (français / arabe) pour **SG Palette (SGP)**, fabricant
N°1 de palettes en bois en Tunisie.

Cette variante **Swiss Minimal** adopte un style monochrome et typographique :
palette quasi noir-et-blanc sur papier cassé, un seul accent (teal `#16A085`),
grille suisse à filets fins (hairlines 1 px), titres grotesk surdimensionnés et
mise en page éditoriale asymétrique de type catalogue / musée.

- Langue principale : **français** (`<html lang="fr" dir="ltr">`), bascule arabe RTL au runtime.
- Contenu et scripts partagés (`js/`, `assets/`) — non modifiés par le thème.
- URL en ligne : <https://ghassentimoumi.github.io/sg-palette-mono/>

## Développement

Ouvrir `index.html` dans un navigateur, ou servir le dossier statiquement.
Vérification QA :

```bash
node scripts/check.mjs
```
